# 满月水母灯

![满月水母灯预览](preview.png)

透明伞盖中悬着一轮发光的月球，下方是柔软的丝带状触须与金色细线。这是参考 AI 图像与视频，在 Blender 中重建可编辑场景的实验。

## 有什么

- 分离的伞盖、金色骨架、月球、宽触须、细线和末端灯珠。
- 宽触须使用 Cloth 模拟，细金线使用 Soft Body 弹簧链。
- 小幅伞盖呼吸与上下浮动；这些是关键帧动画，不是流体模拟。
- 烘焙后的动画工程，以及用于重新调整物理参数的设置工程。

## 已知限制

- 这是可编辑三维近似，不是原视频工程，也不是逐帧精确复刻。
- 运动采用布料/软体受力近似，并非完整水体流场模拟。
- 五秒动画不是无缝循环。
- 细金线与宽触须之间没有统一接触求解；参考未提供的背面结构包含推断。
- 当前按演示渲染制作，**不是已优化、已验收的游戏运行时模型**。尚未发布 GLB/FBX。
